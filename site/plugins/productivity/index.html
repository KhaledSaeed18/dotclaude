Plugin productivity · 8 skills, 3 commands

productivity

Session and personal productivity: collaborative brainstorming, plan stress-testing, session handoffs, meeting notes, a decision log, learning plans, a /prime command that loads project context, and a /weekly-review that assembles the week from evidence.

brainstorminghandoffcontextplanning

Install

Add the marketplace once, then install the bundle. Claude Code namespaces its commands (/productivity:name), wires any hooks, and updates it with /plugin marketplace update dotclaude.

/plugin marketplace add KhaledSaeed18/dotclaude
/plugin install productivity@dotclaude
