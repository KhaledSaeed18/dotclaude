Plugin research

research

Investigation toolkit: a deep-research subagent for multi-source work with citations, plus name-clearing skills for software projects (registries, app stores) and for businesses (social handles, storefronts, company registers).

research citations web naming availability branding

Install

Add the marketplace once, then install the bundle. It updates with /plugin marketplace update dotclaude.

/plugin marketplace add KhaledSaeed18/dotclaude
/plugin install research@dotclaude
