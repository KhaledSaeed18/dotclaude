Plugin documentation

docs

Documentation that stays true to the code: architecture decision records with an /adr command, READMEs verified against the repository, developer guides in the four documentation types, and OpenAPI specifications kept in sync in CI.

documentation adr readme openapi technical-writing

Install

Add the marketplace once, then install the bundle. It updates with /plugin marketplace update dotclaude.

/plugin marketplace add KhaledSaeed18/dotclaude
/plugin install docs@dotclaude
