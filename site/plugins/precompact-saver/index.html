precompact-saver

Context-preservation hook that snapshots the full session transcript before every compaction, keeping the newest ten snapshots per project.

compaction transcript context

Install

Add the marketplace once, then install the bundle. It updates with /plugin marketplace update dotclaude.

/plugin marketplace add KhaledSaeed18/dotclaude
/plugin install precompact-saver@dotclaude
