Plugin security

security

Security review toolkit: OWASP-aligned code review, dependency and secret auditing skills, a security-auditor agent, and a full-codebase /security-audit command.

owasp audit secrets dependencies

Install

Add the marketplace once, then install the bundle. It updates with /plugin marketplace update dotclaude.

/plugin marketplace add KhaledSaeed18/dotclaude
/plugin install security@dotclaude
