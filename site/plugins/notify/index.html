notify

Desktop notifications for Claude Code: surfaces permission requests and attention prompts as native macOS/Linux notifications so long sessions can run in the background.

notifications desktop background

Install

Add the marketplace once, then install the bundle. It updates with /plugin marketplace update dotclaude.

/plugin marketplace add KhaledSaeed18/dotclaude
/plugin install notify@dotclaude
