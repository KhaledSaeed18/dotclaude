Plugin writing

writing

Prose for a human reader: strip machine-writing tells from any text, draft emails that get answered, and outline talks and defences slide by slide.

writing editing humanize prose

Install

Add the marketplace once, then install the bundle. It updates with /plugin marketplace update dotclaude.

/plugin marketplace add KhaledSaeed18/dotclaude
/plugin install writing@dotclaude
