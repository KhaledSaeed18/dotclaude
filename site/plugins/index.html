Plugins

A plugin is a bundle of related items that Claude Code manages for you: one command installs it, hooks activate on install, commands are namespaced, and /plugin marketplace update dotclaude keeps every bundle current.

/plugin marketplace add KhaledSaeed18/dotclaude

Run once, then any /plugin install below works.
