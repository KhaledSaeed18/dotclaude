tool-call-logger

Observability hook that appends one sanitized JSON line per tool call to a local log, with secret redaction and payload truncation.

loggingobservabilityaudit

Install

Add the marketplace once, then install the bundle. Claude Code namespaces its commands (/tool-call-logger:name), wires any hooks, and updates it with /plugin marketplace update dotclaude.

/plugin marketplace add KhaledSaeed18/dotclaude
/plugin install tool-call-logger@dotclaude
