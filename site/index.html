    Plugins are bundles managed by Claude Code. Hook plugins activate on install with no settings.json editing. Add the marketplace once, then install any bundle.

    /plugin marketplace add KhaledSaeed18/dotclaude

      Two ways to install

      As a plugin

      Bundles of related items, managed by Claude Code. Updates with /plugin marketplace update dotclaude, namespaces commands (/security:security-audit), and wires hooks automatically.

      /plugin marketplace add KhaledSaeed18/dotclaude
      /plugin install engineering@dotclaude

      A good starter set is engineering, git, and security-hooks.

      As a single item

      The shadcn CLI copies one item into the project you run it from, under .claude/. Hooks installed this way need their documented block added to .claude/settings.json.

      npx shadcn@latest add KhaledSaeed18/dotclaude/handoff

      To make an item global, copy it from .claude/ into ~/.claude/: folders for skills and hooks, single files for agents and commands.

      What each type is

      Skill
      A procedure Claude loads on its own when your request matches its description. You never call it by name. Installs to .claude/skills/<name>/.
      Agent
      A specialist Claude hands a whole side task to, in its own context, returning only the result. Installs to .claude/agents/<name>.md.
      Command
      A shortcut you trigger yourself by typing /name. Installs to .claude/commands/<name>.md.
      Hook
      A script that runs on a Claude Code event, every time, with no model judgment. Installs to .claude/hooks/<name>/.
